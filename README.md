# 人员考勤管理系统

全栈人员考勤管理系统，覆盖月度考勤管理、加班/休假申请审批、人员班组管理、角色权限管理。

## 技术栈

- **前端**：Vue 3 + Vite + Ant Design Vue 4 + Pinia + Vue Router + Axios
- **后端**：Node.js + Express + MySQL 8.x（mysql2）+ JWT + bcryptjs
- **数据库**：MySQL

## 功能模块

1. **月度考勤管理** — 人工录入、未达标标红、加班/年假抵扣
2. **加班工时管理** — 每 3 小时为 1 个加班单位，整数单位抵扣
3. **假期管理** — 年假（按工龄分档初始化）、婚丧嫁娶（申请录入）
4. **申请审批流程** — 员工发起 → 班组长审核 → 管理人员确认录入
5. **人员管理** — 入职/离职、班组分配
6. **班组管理** — 班组增删、班组长指派
7. **角色权限** — 员工 / 班组长 / 管理人员

## 核心业务规则

- 加班：每 3 小时 = 1 个加班单位（1 行记录），抵扣时 1 单位 = 0.5 天，3 单位 = 1 整天
- 年假：1-10 年 5 天 / 10-20 年 10 天 / 20+ 年 15 天，每年 1 月 1 日初始化，12 月 31 日清零
- 婚丧嫁娶：需申请 → 审核 → 录入，0.5 天颗粒扣减
- 考勤标准：08:20–17:00，有效工时 < 8 小时标红

## 启动步骤

### 1. 准备 MySQL 数据库

确保本地 MySQL 8.x 已启动，然后执行建表脚本：

```bash
mysql -u root -p < server/sql/init.sql
```

### 2. 启动后端

```bash
cd server
npm install
cp .env.example .env
# 编辑 .env 修改数据库密码等配置
npm run init-db    # 初始化管理员账号 admin/admin123
npm run dev        # 启动后端，端口 3000
```

### 3. 启动前端

```bash
cd client
npm install
npm run dev        # 启动前端，端口 5173
```

### 4. 访问系统

浏览器打开 http://localhost:5173，使用 `admin / admin123` 登录。

## 端到端测试流程

1. **管理员登录** → 班组管理创建班组 → 人员管理创建班组长和员工
2. **年假初始化** → 进入"年假初始化"页面，预览并确认
3. **员工登录** → 发起加班申请（如 7 小时 → 生成 2 个加班单位）
4. **班组长登录** → 审核通过加班申请
5. **管理员登录** → 确认录入（生成加班单位）
6. **管理员录入月度考勤** → 制造短缺数据（标红）
7. **管理员执行抵扣** → 用加班单位或年假抵扣短缺
8. **员工发起休假申请** → 消耗加班单位/年假 → 审核 → 录入
